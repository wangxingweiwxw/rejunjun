# 生化骏骏危机

使用 Three.js 制作的过肩第三人称生存射击游戏。在线游玩：https://rejunjun.chipai.cc

当前版本同步自 2026-10-30 的小工具优化构建：儿童主角、过肩镜头贴墙回缩、更明亮的研究所、静态墙体空间查询、命中/爆头/击倒反馈和受击方向提示。保留已保存的省电画质设置。

## 操作

触屏：左摇杆移动，右侧滑动转向，按住开火；瞄准和疾跑按钮切换状态。
电脑：WASD 移动，左键射击并拖动转向，右键瞄准，R 换弹，Q 切枪，E 交互，Shift 疾跑，F 手电，H 治疗，Esc 暂停。

目标：取得档案室保险丝，恢复供电，完成五波防守，在北端出口撤离。

## 开发与部署

需要 Node.js。已提交可直接发布的压缩脚本及模型资源，普通部署不需要重新转换模型。

```bash
npm test
npm run build
npm run preview
npm run deploy
```

- `source/` 是当前游戏的可编辑 JavaScript 源码；修改后先执行 `npm run bundle`，再构建/部署。打包器固定为 esbuild 0.28.1，目标为 ES2017 / Chrome 61。
- `index.html`、`style.css`、`assets/`、`notices.json` 是当前发布资源。
- `build.mjs` 使用明确清单将 13 个运行文件复制到 `dist/`，并检查总量不超过 10,000,000 字节。
- `wrangler.jsonc` 保持 Worker 名称 `rejunjun`、构建命令和 `./dist` 静态资源目录。已有域名绑定由 Cloudflare 管理。
- 根目录旧 `game.js`、`core.js`、GLB 和 `vendor/` 保留为早期第一人称版本参考，不进入当前部署；请编辑 `source/` 下的当前源码。
- 本仓库提供已转换的模型与贴图；不包含家庭参考视频、照片、对比报告或本机开发缓存。

当前发布资源共 8,442,128 字节。对应小工具 ZIP 为 3,938,083 字节，均低于 10 MB。修改后以构建的实际检查结果为准。
