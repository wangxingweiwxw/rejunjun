# RE Junjun

**RE Junjun** 是使用 Three.js 制作的触屏 3D 生存射击网页原型，包含研究所探索、五波防守和撤离任务，支持手机触屏与电脑键鼠。提供原创关卡与界面；使用的开源代码和素材归属详见 `THIRD_PARTY_NOTICES.md`。

## 立即游玩

- **电脑直接打开 `RE-Junjun-即玩版.html`**。资源全部内嵌，无需 CDN、安装包或构建步骤。使用现代 Chrome / Edge / Safari。
- **手机推荐**：双击 `启动游戏.cmd`，手机与电脑连接同一 Wi-Fi，在手机浏览器访问启动窗口显示的电脑局域网地址。此方式需要电脑安装 Python，并在试玩期间保持服务器运行。若系统询问网络访问，请按实际网络环境设置。
- 源码启动：`python serve.py --open`，电脑打开 `http://localhost:8765`。默认端口被占用时用 `python serve.py --port 8766 --open`。
- 也可将整个目录上传到任意静态网站托管，直接访问 `index.html`。本次未部署公网地址。部分手机文件预览器不执行 HTML 脚本，手机建议通过浏览器网址游玩。

服务仅提供当前项目目录的静态文件，监听局域网接口供手机访问，不需要用户账号。

## 操作与流程

触屏：左摇杆模拟移动；右侧滑动转向；按住开火连续射击，开火按钮上滑动也能转动视角。瞄准与疾跑按钮为开关。换弹、切枪、医疗、手电各有独立按钮。物品与门禁附近会出现交互按钮。横屏视野最佳，竖屏同样有可操作布局。

键鼠：WASD 移动，鼠标瞄准，左键射击，右键瞄准，R 换弹，Q 切枪，E 交互，Shift 疾跑，F 手电，H 治疗，Esc 暂停。首次点击画面取得鼠标控制；支持带触摸屏电脑切换鼠标。

完整流程：

1. 初始手枪、12 发弹匣、72 发备用弹药、1 个医疗包、200 积分。
2. 沿走廊北行，解锁左侧档案室（250 分），进入拾取保险丝。
3. 返回走廊南段，解锁右侧供电室（500 分），安装保险丝。
4. 完成五波防守，感染者数量分别为 5 / 6 / 7 / 8 / 9。
5. 沿主走廊前往北端出口，交互撤离。

击杀 60 分，爆头击杀 100 分；波次间奖励 100 分，并补充弹药和少量生命。击杀有 40% 几率掉落补给。医疗包恢复 55 生命。医务室可买 M870（600 分），实验室可买 AR-18（800 分），已购买武器可付费补弹。房门解锁永久有效，敌人也会通过已打开的门追踪玩家。

## 相比三个附件的改动

- 从《暗黑研究所》版本的“追踪玩家坐标”升级为网格距离场寻路；墙体与关闭房门同时阻挡玩家、敌人与射线。
- 修复附件 (10)/(12) 中子弹只按敌人脚部位置判断距离、忽略墙体的问题。改为射线命中头部 / 躯干 / 腿部碰撞体，以最近的墙体或敌人为准；增加爆头奖励、命中提示、枪口闪光和后坐。
- 将点按射击、`touches[0]` 摇杆改为独立 Pointer ID 与指针捕获，支持多指与取消事件；模拟摇杆保留力度，不再只是八方向移动。
- 换弹有实际耗时；增加备用弹药管理、武器购买、疾跑耐力、医疗包、手电、辅助瞄准与合成音效。
- 新增五波生存、积分门禁、保险丝与供电、撤离、暂停、死亡结算与重开；切出页面会自动暂停。
- 使用上游真实的骨骼丧尸模型、纹理和动画，以及 Quaternius 枪械模型。替换附件中的基础几何人物，关闭重复 LOD 网格；流畅画质使用 LOD2，精细画质使用 LOD1。
- 合并静态几何，复用纹理与材质，限制场上敌人 / 尸体 / 补给 / 特效数量，控制像素比并在持续低帧率时降分辨率。依赖全部本地化。
- 新增研究所分区、门禁标识、程序纹理、照明、雾、第一人称武器与中英文 HUD；支持亮度 / 灵敏度 / 声音设置并保存偏好。

## 验证与已知范围

- `node --test tests/core.test.mjs`：波次 / 积分公式、开门前后寻路、墙体防穿透、沿墙滑动、弹药守恒，共 5 项。
- `python tests/mobile_check.py`：Chrome 手机模拟，844×390 横屏和 390×844 竖屏；CDP 三指实际触摸事件，移动 + 转向 + 持续射击、取消触摸、暂停冻结、爆头、换弹、墙体遮挡、门禁、保险丝、供电、撤离与重开。
- `python tests/release_check.py`：单文件以 `file://` 打开，不产生 HTTP 请求；键盘移动、敌人跨房间绕角寻路、完整五波 35 敌人流程、死亡与重开。
- 浏览器测试依赖 Python Playwright 和本机 Chrome，脚本内的 Chrome 路径可按环境调整。源码浏览器测试需要先启动 `serve.py`。
- 测试结果存于 `tests/*-results.json`。没有真实 iPhone / Android 设备测试，因此不保证具体机型帧率或所有 Safari 版本表现；浏览器软件渲染帧率不代表手机 GPU 表现。
- 命中使用与模型尺寸匹配的碰撞体，而非逐三角形骨骼命中。墙体 / 房门有碰撞，部分装饰道具尚无独立物理碰撞。没有自动存档、联机或无限波次。
